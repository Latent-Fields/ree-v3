# REE V3 Public Entry Page

`index.html` is the public technical entry page for this repository. It is a navigation layer, not a replacement for the stable repository README or the V3 specification.

The page uses the shared shell published by `Latent-Fields.github.io/assets/public-shell-v1.css`. Keep the V3-specific layout in `assets/public-entry.css`, and preserve the routes to REE Assembly, the V3 status history, the specification, and the source repository.

The page reads the public GitHub repository API to show the latest source update date. It is deliberately limited to repository metadata; current claim, evidence, and governance state remain canonical in REE Assembly.

When changing the V3 public entry page, also read `https://latent-fields.github.io/docs/public_site_design.html` and verify the deployed desktop and mobile layouts after Pages rebuilds.
