# V3 Status Records

This directory holds operational status material that changes more frequently
than the repository's stable onboarding documentation.

## Read These First

- [Repository README](../../README.md): stable purpose, boundaries, and entry
  points for contributors.
- [V3 specification](../ree-v3-spec.md): component and substrate reference.
- [Current cross-program frontier](https://github.com/Latent-Fields/REE_assembly/blob/master/docs/CURRENT_FRONT.md):
  the live research picture generated from canonical records.
- [Nightly status history](nightly_history.md): dated V3 snapshots in reverse
  chronological order. The most recent preserved entry is 2026-07-27.

## Update Rule

`README.md` is not a nightly log. A nightly documentation update may revise it
only when the stable purpose, boundaries, entry points, or usage guidance have
changed.

Put dated V3 snapshots in `nightly_history.md`, newest first. A snapshot should
link to canonical evidence and planning records rather than duplicate them when
possible. It must not expose machine details, credentials, private paths, or
unreviewed operational information.

The status history is an audit trail, not the canonical source of claim state,
experiment review, or queue state. Those sources remain in `REE_assembly`.
